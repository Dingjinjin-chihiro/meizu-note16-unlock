# KernelSU 模块指南（针对本机）

> 设备：MEIZU Note 16（M521Q）· Android 15 · KernelSU v3.3.1 **LKM 模式**
> 前提：BL 已解锁 · `init_boot_a` 已打补丁 · 完整备份在 `_backup/`

## 三条铁律

1. **一次只装一个模块**，重启验证正常后再装下一个。出问题时你才知道是谁。
2. **装前确认兜底可用**：BROM 能进、`_backup\init_boot_a.bin` 在、`spd_dump` 能跑。
3. **不装需要改系统分区的模块**。dm-verity 仍 `enforcing`，任何"替换 /system 文件"的做法都会导致起不来；
   模块只能走 overlay，不能真改分区。

## 出问题的三级处理

| 现象 | 处理 |
|---|---|
| 能进系统，某功能异常 | KSU 管理器里关掉该模块 → 重启 |
| 卡在开机动画 | `adb shell rm -rf /data/adb/modules/<模块ID>`（需 root 授权）→ 重启 |
| 完全黑屏 / 连不上 | 进 BROM，`spd_dump` 写回 `_backup\init_boot_a.bin` → 重启 |

最后一条是终极兜底，两分钟恢复，所以**大胆试**。

## 推荐安装（按用途）

| 用途 | 模块 | 说明 |
|---|---|---|
| Zygisk 支持 | **Zygisk-Next** | 后面 LSPosed、Shamiko 都依赖它；装完重启确认 KSU 里显示已启用 |
| Xposed 框架 | **LSPosed**（Zygisk 版） | 需要先有 Zygisk；装完在桌面出现 LSPosed 管理器 |
| 隐藏 root | **Shamiko** | 配合 Zygisk，对指定 App 隐藏 root |
| 完整性伪装 | **TrickyStore / PIF** | 让 Play Integrity 之类检测通过；版本更替快，需跟着更新 |
| 性能/温控 | **KernelSU Tuner** | 你在仓库里看到的那个，按温度/屏幕状态自动切性能档，还带充电限流 |
| 去广告 | **AdAway**（root 模式） | 走 hosts，全局拦截；不要选"直接改 /system"选项 |
| 字体/主题 | 字体模块 | 走 overlay，相对安全；别选"替换系统字体服务"的 |

## 慎装

- **改 framework / 系统服务**的模块（"全局去限制""解锁高刷"这类）：容易和 Flyme 的定制逻辑打架。
- **改内核参数**的模块：LKM 模式下能改 `sysfs`，但改错电压/频率会随机重启。
- **来源不明的闭源模块**：模块以 root 运行，等于把整机交出去。

## 不要装

- 声称"永久解锁 / 改 IMEI / 解除运营商锁"的 —— 要么无效，要么违法。
- 要求关闭 verity 的 —— 你这台 dm-verity 是 `enforcing`，关了会破坏 OTA 与分区完整性。
- 与本机 KMI 不匹配的（`android13-5.15`）—— 加载会失败，严重时启动卡死。
