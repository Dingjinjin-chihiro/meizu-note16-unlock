## 一、方法与安全边界

### 用 `pm uninstall --user 0`，不用删分区

```powershell
adb shell pm uninstall --user 0 <包名>        # 删除（APK 仍留在 /system）
adb shell cmd package install-existing <包名> # 恢复
```

- **APK 留在系统分区**，随时可恢复，不碰 dm-verity
- **只影响当前用户**，不动系统镜像本身
- 恢复出厂 / 重刷固件后自动回到原样

### 动手前先备份 APK

```powershell
adb pull /system/app        _apk_backup/system/app
adb pull /system/priv-app   _apk_backup/system/priv-app
adb pull /product/app       _apk_backup/product/app
...（system_ext、vendor、overlay 同理）
```

备份结果：**612 个文件 / 3.84 GB**，覆盖 system、system_ext、product、vendor、odm 全部应用目录。

### B 级（101 个，为什么保留）

| 类别 | 例子 | 删了的后果 |
|---|---|---|
| 资源 / overlay | `wifi.resources*`、`networkstack.overlay*`、`color_display.overlay` | WiFi 配置、网络参数异常 |
| SystemUI 扩展 | `flyme.systemuiex`、`systemuitools`、`systemuieditor` | 状态栏 / 下拉通知栏异常 |
| 安全 / 生物识别 | `org.ifaa.aidl.manager`、`com.tencent.soter.soterserver` | 指纹解锁、微信指纹支付失效 |
| 电源 / 性能 | `meizu.battery`、`powersave`、`perfui`、`superalgorithmservice` | 功耗调度、温控失效 |
| 基础服务 | `meizu.safe`、`privacy`、`location`、`share`、`netcontactservice` | 权限弹窗、定位、分享、联系人异常 |

### C 级（13 个，最终全删）

相机、图库、文件管理、时钟、日历、录音机、便签、计算器、浏览器、邮件、SIM 卡工具、小区广播 ×2。

## 三、两个名字极具误导性的包

排查时差点漏掉的两个：

| 显示名 | 包名 | 实际 APK 位置 |
|---|---|---|
| **家庭守护** | `com.meizu.sceneinfo` | `/system/MzApp/FamilyGuard/FamilyGuard.apk` |
| **场景引擎 / 场景助手** | `com.flyme.sceneengine` | `/system/MzApp/SceneEngine/SceneEngine.apk` |

**教训：不要按包名猜功能。** 这两个第一次都被归进「B 级保留」，是用户看到桌面图标才发现没删掉。正确做法是看 APK 所在目录名，或直接解析 APK 的 label。

## 五、恢复

```powershell
_dump\恢复全部自带应用.ps1     # 127 条
```

单条：

```powershell
adb shell cmd package install-existing com.meizu.media.camera
adb shell cmd package install-existing com.flyme.sceneengine
```

> **例外**：微博（`com.sina.weibo`）和哔哩哔哩（`tv.danmaku.bili`）是**应用数据区**的应用，
> 系统分区没有 APK，`install-existing` 无法恢复。要恢复只能重新下载安装。

## 六、已知副作用

| 现象 | 原因 |
|---|---|
| 设置里「辅助功能 → 游戏模式 / 户外工作模式」点了没反应 | 依赖已删除的 `com.flyme.sceneengine` |
| 设置里「Aicy 和 AI」入口空白 | AI 相关包已删 |
| 桌面图标残留 | Flyme 桌面缓存，长按删除或重启后消失 |
| 无相机 / 图库 / 文件管理 / 时钟 / 日历 / 计算器 | 按需求删除，需自行装第三方 |
| 来电铃声无法更换 | `com.android.soundpicker` 属于 B 级，保留，不受影响 |
