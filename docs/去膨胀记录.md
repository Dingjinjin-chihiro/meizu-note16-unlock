# 系统精简记录（Flyme 去膨胀）

> 设备：MEIZU Note 16（M521Q / UMS9621S）· Flyme 12.0.1.7A · Android 15
> 前提：Bootloader 已解锁 + KernelSU(LKM) root · dm-verity 仍 enforcing
> 日期：2026-11-01

## 原则

1. **只冻结，不卸载**——系统应用一律 `pm disable-user --user 0`，随时 `pm enable` 还原。
2. **只动第三方预装才卸载**——用 `pm uninstall --user 0`，可用 `cmd package install-existing` 还原。
3. **不碰保护名单**——启动器、SystemUI、电话、短信、设置、WebView、相机、图库、文件管理、输入法、蓝牙/NFC、网络栈、TEE/IFAA 等一律保留。
4. **不写 system**——dm-verity 仍 enforcing，任何"改系统分区"的想法都靠 systemless 模块，不做直接替换。

## 已知副作用

- 设置里「账号与同步」「系统更新」「应用商店」等入口消失或点击无响应（对应包已停用）。
- OTA 提示不再出现（BL 已解锁，本来也会失败）。
- NFC 刷卡、魅族支付、云同步、查找手机不可用。
- 系统推送通道（`com.meizu.pps`）停用，第三方 App 需走各自推送。

## 未采用的方案

**Private DNS 去广告**：测试 `dns.adguard-dns.com` 时 ICMP 100% 丢包，在本地网络下强行启用有整机断网风险，故不采用。如需 DNS 级拦截，建议自行在路由器或支持 DoT 的本地 DNS 上做。
